# ❤️ Love Website — Premium Romantic Project

A fully rebuilt, modern romantic single-page website built using **HTML, CSS, and Vanilla JavaScript**.

Designed to be elegant, smooth, responsive, and emotionally interactive.

---

## ✨ Features

### 🔐 Password Screen
- Fullscreen entry gate
- Arabic password system: **"حنتوشتي"**
- Shake animation on wrong input
- Smooth transition on success

---

### 🌌 Visual Effects
- Animated stars background (canvas)
- Floating hearts ❤️ and roses 🌹
- Mouse glow effect
- Click sparkle animation ✨
- Confetti celebration system 🎉

---

### 💌 Content Sections
- Hero section with romantic title
- Animated love letters (typing effect)
- Responsive photo gallery
- Fullscreen lightbox (keyboard + touch support)
- Live love counter since **2020-01-01**

---

### ❓ Interaction System
- “هل تحبيني؟” question
- YES button triggers celebration
- NO button evades cursor dynamically

---

### 📱 Responsive Design
- Mobile-first layout
- Optimized for:
  - iPhone
  - Android
  - Tablets
  - Desktop screens

---

### ⚡ Performance
- No external libraries
- Lightweight animations
- Lazy image loading
- Optimized rendering

---

### ♿ Accessibility
- Keyboard navigation support
- Reduced motion support
- Focus states for inputs/buttons
